Transkripte codieren

Private integrierte Vorbereitung. Markiere Text innerhalb eines Segments und weise eine Kategorie zu. Mehrfachcodierungen sind möglich. Manuelle Arbeit bleibt lokal. Optionale LLM-Vorschläge werden unten ausdrücklich angefordert; jeder Vorschlag bleibt prüfpflichtig.

Über die lokale Arbeitsansicht werden Textzuordnungen, Kategorien und Codierungen automatisch auf Datenträger gespeichert. „Projekt als JSON speichern“ erzeugt zusätzlich eine portable Sicherung. Als direkt geöffnete HTML-Datei steht nur die Browser-Zwischensicherung zur Verfügung. Auf den angezeigten Speicherstatus achten.

Noch kein Projekt geladen.

Vorhandenes Transkript importieren

Unterstützt werden Transkriptexporte, keine nativen f4-/MAXQDA-/ATLAS.ti-Projekte. Vorhandene Codes/Memos werden dabei nicht automatisch übertragen.

Textstelle zuordnen

Noch keine Textstelle markiert.

Der Import bezieht sich auf das ausgewählte Dokument und akzeptiert nur zuvor bestätigte Vorschläge mit passenden Textbelegen.

Export

CSV mit Semikolon und UTF-8. Im Analyseprogramm: Code → Code; Text → Segment; Person → Dokumentname; Passage-ID → PassageID. Dokumentname enthält bewusst die bestätigte Personenkennung; Quelldokument bewahrt den Dateibezug.

CSV direkt in das Analyseprogramm importieren. Beim Öffnen in Excel alle Spalten als Text behandeln: Originalzitate bleiben unverändert und können mit Formelzeichen beginnen.

Bei Gruppeninterviews die Personen je Segment festlegen. Enthält ein Segment mehrere Personen, zunächst das Transkript entsprechend aufteilen und neu bestätigen. Interviewfragen können vom Export ausgeschlossen werden. Zeitangaben beziehen sich auf das gesamte ASR-Segment.
