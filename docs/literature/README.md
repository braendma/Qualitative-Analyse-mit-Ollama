## Einordnung

Dies ist eine gezielte Literaturauswahl, kein systematisches Review. Die
Veröffentlichungen vertreten unterschiedliche Positionen. Die konkreten
Zählregeln, Prüfstatus und getrennten Analyseperspektiven sind begründete
Projektentscheidungen; die Quellen sind keine empirische Validierung dieser
Software oder einer bestimmten automatischen SWOT-Gewichtung.
