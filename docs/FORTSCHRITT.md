# Fortschritt der 20 Module

Der obere Balken zählt vollständig abgeschlossene Module. Er zeigt keinen Anteil der Gesamtlaufzeit. Die Arbeitseinheiten einzelner Module können sehr unterschiedlich lange dauern und jeweils mehrere Modellanfragen auslösen.

| Modul | Angezeigte Arbeitseinheiten oder Phasen |
| --- | --- |
| Clusteranalyse | abgeschlossene Kategorien |
| Codeprüfung | bearbeitete Codierzeilen, bei Mehrfachcodierung Passagen |
| Blind-Coding | bearbeitete Codierzeilen, bei Mehrfachcodierung Passagen |
| Codierübereinstimmung | Vorbereitung und vollständiger Abschluss der Berechnung/Ausgabe |
| Zusammenfassungen | Clusterzusammenfassungen plus abschließende Gesamtzusammenfassung |
| SWOT | abgeschlossene Kategorien |
| Meta-SWOT | vier SWOT-Dimensionen; Prüfblöcke der aktuellen Dimension separat |
| Personenanalyse | abgeschlossene Personen |
| Personenvergleich | gegebenenfalls Vorbereitung je Person; danach eigene Phase für den abschließenden Vergleich |
| Kontrastanalyse | abgeschlossene Prüfblöcke |
| Zusammenhangsanalyse | Vorbereitung der Codepfad-Paare; danach abgeschlossene Prüfblöcke |
| Ambivalenzanalyse | abgeschlossene Personen; Prüfblöcke der aktuellen Person separat |
| Evidence-Audit | abgeschlossene Prüfblöcke |
| Prüfliste | Vorbereitung und vollständiger Abschluss der Erstellung/Ausgabe |
| Gesamtsynthese | gegebenenfalls Verdichtungsblöcke je ausdrücklich benannter Ebene; danach eigene Abschlussphase |
| Coverage und Blind Spots | geprüfte Quellen und Erstellung der deterministischen Verteilungen |
| Information-Loss-Audit | geprüfte Quellenübergänge und Erstellung der Prüfpunkte |
| Codebook-Diagnostik | Prüfung der verfügbaren Analysequellen und Diagnoseausgabe |
| Stabilitätsanalyse | zusätzliche Wiederholungen; aktuelle Kindlaufmodule und deren gemeldete Arbeitseinheiten separat |
| Sensitivitätsanalyse | Einstellungen und deren Wiederholungen; aktuelle Kindlaufmodule und deren gemeldete Arbeitseinheiten separat |

Bei den zehn dafür geeigneten Modulen ergänzen „Häufigkeiten“ oder „Beide“ die erforderliche Themenzuordnung und Häufigkeitsinterpretation als eigene Phasen. Bei der Gesamtsynthese wird davor die modellseitige Auswahl vollständiger Synthesebefunde mit der aktuell bekannten Kandidatenzahl angezeigt. Cluster und Cluster-Zusammenfassungen verwenden bereits vorhandene vollständige Zuordnungen. „Beide“ teilt die Matrix und die Syntheseauswahl; es startet keine doppelte Zählung. Diese Zusatzphasen sind kein Anteil der gesamten Laufzeit.

Prozentwerte beziehen sich nur auf die angezeigten Einheiten der jeweiligen Phase. Bei einem Phasenwechsel kann der Zähler neu beginnen; die Phase wird benannt. Untergeordnete Prüfblöcke überschreiben keine Personen- oder Dimensionszähler. Ist die Gesamtzahl noch unbekannt, erscheint eine Aktivitätsanzeige ohne Prozentwert. Bei null Arbeitseinheiten wird dies ausdrücklich angegeben. Antwortzahlen und Zeitstempel sind zusätzliche Hinweise; längere Zeit ohne neue Antwort beweist allein keinen Fehler.

Ein fehlgeschlagener Schritt zählt nicht als abgeschlossen. Beim Wiederaufnehmen zählen erfolgreich verifizierte Zwischenergebnisse wieder als erledigt. Der Modulabschluss wird erst nach erfolgreicher Rückkehr des gesamten Programms einschließlich seiner Ausgaben gemeldet. Die kurzen Schritte Codierübereinstimmung und Prüfliste erhalten bewusst keine erfundene kleinteilige Zeitschätzung.
